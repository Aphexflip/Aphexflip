## Professional background

In customer facing industrial engineering roles at **Velo3D, Zünd and Fujifilm**, I worked on technical troubleshooting, equipment operations and training. At Velo3D, I used **Grafana** to interpret machine telemetry and diagnose issues in complex metal 3D printing systems.

That experience shapes how I approach software: investigate what is actually happening, isolate failures, preserve working states, test changes and communicate clearly.

## Engineering approach

I design the requirements and system behavior and use AI coding tools extensively to prototype and iterate. AI assistants contribute substantial implementation code in some projects. I review, test and refine the results, and distinguish **tested functionality** from **ideas and prototypes**.

I want to build technology that solves real problems and is genuinely useful to other people.
